## 总结

做一支约 90 秒的 `ElectricSedan` 演示，给第一次看产品的技术人员。主画面是 Agent 对话，旁边的 **Models** 用源码、几何、仿真三张卡片跟上产物。

一次 **Auto** 运行按原速录完。成片从这次实录里按产物顺序硬切：需求、写出 SysML 与 Modelica、提交一份 Euler FMU、校验通过、模型图、几何（STL 在上、彩色 PNG 在下）、仿真从「进行中」到完成、`battery` / `inverter` / `motor` 三条轨迹、判据通过时的终值。

## 成片要完成的事

观众看完能复述这条路径：

自然语言需求 → SysML 与一份 Euler FMU → 源码与诊断 → 模型图 → 几何 → 绑定该 FMU 的仿真 → 三条轨迹与观测判据

仿真曲线来自这次 FMU 求解。STL 和彩色 PNG 来自同一次 OpenSCAD 作业。成片停在这三步都完成的时刻。

现有 `Daidalis-Demo.mp4`（约 3 分 18 秒）提供模型、视图和结果的特写。执行过程和作业状态用这次实录。已保存的运行以记录回放呈现。

## 录制

- **Models** 打开，放在对话旁边。权限为 **Auto**，运行一路完成。
- 对话留在主页面。模型特写都在 Models 里完成。
- 源码卡使用 **源码**、**诊断**、**模型图**；需要对照开口里的动力总成时，切到 **实物预览**。
- 卡片在写入或计算完成时自己展开。剪辑顺着这个顺序。

## 十几分钟的实录怎么收成 90 秒

整段按原速录下来。成片用硬切接上下面六个节点，每段两到四秒：

1. 写出 SysML，源码卡打开。
2. 写出 Modelica，留在对话的文件记录里。
3. 提交 FMU 导出。
4. 校验通过。
5. 几何卡显示「几何生成中」，下一刀是 STL 和 PNG。
6. 仿真卡显示「仿真进行中」，下一刀是「执行完成」。

观众看到的是同一次运行的先后顺序。旁白说明这一步留下了什么产物。

- 画面只保留产品界面，比例保持原样。
- 执行段以对话为主，模型段以当前展开的卡片为主，标题留在画面内。完整界面用在建立整车和部件位置关系的时候；代码、结构图、几何和曲线用近景。

- 仿真回放使用信号卡和时间轴。
