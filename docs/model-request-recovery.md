# 模型请求恢复

通用 API 连接（OpenAI Chat Completions、Responses、Anthropic、Ollama）的默认设置为：

- 单次请求超时 300 秒。
- 首次失败后最多重试 5 次，共最多 6 次请求。
- 默认重试间隔为 5、10、20、40、60 秒。
- 从首次可重试失败起，恢复过程最多持续 300 秒，包括等待和后续请求本身。后续请求的超时取连接配置与剩余恢复时间中的较小值。

恢复预算按每个逻辑模型请求独立计算，首次请求的执行时间不计入恢复预算。整个 Agent 运行仍受项目执行预算约束，用户取消会立即结束等待或请求。

仅重试超时、连接故障、临时限流和服务端错误。认证失败、请求参数错误及明确的 `insufficient_quota` 等额度耗尽错误直接返回。服务端提供有效的 `Retry-After` 或 `retry-after-ms` 时遵守其等待时间；如果等待时间超出剩余恢复预算，停止并提示稍后继续，不提前重试。默认等待间隔超出剩余预算时也停止，并明确说明剩余恢复时间不足。

重试只覆盖当前模型请求，不重新执行之前完成的工具或从头启动任务。恢复预算耗尽后，运行标记为中断，已有文件、工具结果及 SDK 会话保留，可在同一对话继续。达到重试次数上限时也会保留这些内容并显示继续执行的提示。

设置中的“失败后重试次数”仍允许配置 0–5 次。新建连接默认 5 次；已有连接明确保存的数值保持不变，需要时在设置中修改并保存。此策略不改变 Codex 或 Claude 原生运行时自身的请求恢复行为。
